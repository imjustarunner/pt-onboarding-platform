# Verification rollout — September 18, 2026

Application two-step verification is optional for all roles, including enrolled users and designated privacy reviewers. Google SSO sign-ins do not require an additional app factor. No client-name or document restrictions depend on enrollment during this rollout. Authenticator and school-email verification remain available in Security & sign-in activity.

The interface encourages non-SSO users to enroll and explains that mandatory verification is planned over the next few months. There is no scheduled automatic enforcement date. This policy supersedes earlier mandatory-MFA rollout instructions.

Authentication, session expiration and revocation, PIN locks, existing resource permissions, evidence recording, file-volume limits, designated reviewer authorization, and the prohibition on self-approval remain enforced. A Google sign-in marker identifies the sign-in method; it does not attest that Google performed MFA.

Primary setup buttons use white text on a dark green background instead of inheriting tenant text colors.
