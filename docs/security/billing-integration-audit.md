# Family billing integration implementation

Repository implementation reviewed September 11, 2026. This replaces the earlier gap audit. Tests use synthetic records and mocked processors; this is not a production acceptance report or security certification.

| Workflow | Implemented behavior |
| --- | --- |
| Claim copays | Billing staff create a verified patient-responsibility balance against a tenant-scoped, nondeleted claim. One source balance prevents separately charging the same claim as both a copay and a deductible. Cash/cards settle its allocations; the claim list shows the remaining family balance. Adjustments and refunds are audited. |
| Sessions / services | Import unsettled session charges with their immutable source ID. Skip covered, paid and unresolved legacy attempts. An imported charge cannot also collect through the old whole-charge endpoint. Tutoring, coaching, consulting and other classified services use the same ledger. Source changes block collection pending reconciliation. |
| Packages / programs | Pending package orders issue no credits. Full settlement activates the purchased session-count snapshot once, enrolls the package class and runs tutoring hooks. Reviewed event registration balances enroll the client after settlement. Failed activation remains visible and retryable without losing the receipt or repeating credits. |
| Split / alternating payers | Integer-cent shares sum exactly. Changes preserve already-paid amounts. All affected parties must accept a guardian-proposed split; staff can record an authorized arrangement directly. Future charges can alternate among designated payers. |
| Privacy / sharing | Payers see their own allocations by default. Staff can explicitly share statements and receipts with another responsible payer after recording authority. Cards and insurance identifiers remain private to their owner. Client receipts omit payment-method details and use generic service labels. |
| Receipts | Actual successful card or recorded cash payment produces a numbered encrypted receipt. PDF downloads support printing in portal/profile views. Refunds show net paid. Duplicate cash requests produce one posting and receipt. |
| Payment plans | Signed exact amounts/dates, selected owned card, optional automatic collection, revocation, partial-payment allocation and due-installment reconciliation. A payment plan does not silently grant authority over another person's card. |
| Migration tasks | Staff select a guardian and covered clients, add approved waiver terms, and create a portal task plus invitation draft. The expiring random link requires the exact guardian login and returns directly to payment setup. Completion verifies the card's owner/account and saves signed evidence encrypted. Medicaid-covered care cannot receive a mandatory-card task. |
| Collections | Plan-aware overdue shares exclude holds, disputes, unauthorized payers and Medicaid-protected services. Staff generate immutable printable letters, then review/send generic portal notifications. Sending rechecks balance/access and records held/uncertain outcomes instead of retrying blindly. Opt-in automation generates daily drafts and processes previously signed due installments; it does not send emails. |
| Tenant mailboxes | Initialize billing/collections identities from an explicitly configured Workspace domain. Admin provisioning checks membership, applies restricted group settings, registers inbound routes and verifies Gmail send-as. Existing groups require explicit adoption and verified membership. A missing PNG is generated from tenant identity/logo; failed rendering leaves a readable signature. |
| Clinical access | Independent full/limited/payer-only disclosure grants require documented authority and review dates. Age 12 and adulthood trigger review safeguards. Limited grants exclude plans/goals/frequency. Client privacy restrictions apply immediately while clinical review is pending. Portal clinical documents, progress, event disclosure, messages and guardian acknowledgment links check these grants. |
| Enrollment | Branded insurance/payment shell, real progress and save-later navigation, policy/subscriber details, accessible card uploads and direct Stripe Elements. Unknown costs remain pending. Primary/secondary Medicaid suppress mental-health payment prompts and required-card validation. |

## Legacy paths and financial integrity

Legacy placeholder payments and browser-asserted practitioner payment success return 410. Paid manual package activation must use the shared billing desk and an actual recorded payment. Existing practitioner checkout is payment-in-full; unsupported installment/per-session choices route families to an approved billing arrangement. Its server validates amount received, currency, tenant, client, packet, package and mode; saved checkout attempts keep retries on one Stripe key, and transactional activation grants credits once. The existing unified Stripe package checkout records newly verified settlements in the family receipt ledger. Pre-migration payments are not assumed to have payer consent or imported silently.

Refunds hold the balance for review; staff must reconcile already-issued service credits or registrations separately. Existing class/event enrollment capacity policies still need scheduling review before a paid order is offered. Source fulfillment and processor capture are distinct: receiving money is durable even when registration needs staff attention. The desk exposes activation failures and retries. This does not claim automatic ERA/COB adjudication, automatic refund-to-claim remittance posting, or retroactive cleanup of all legacy ledgers.

## Clinical policy basis

Age 12 is a review safeguard, not an assertion that every Colorado parent automatically loses all rights on that birthday. Certain independently consented outpatient psychotherapy has specific clinical/documentation rules. A parent's insurance coverage does not establish an adult child's clinical authorization. Custody, foster placement, minor consent and safety exceptions require recorded review. [Colorado Title 12, §12-245-203.5](https://olls.info/crs/crs2025-title-12.pdf#page=645), [HHS minors' mental-health disclosure guidance](https://www.hhs.gov/hipaa/for-professionals/faq/2092/can-minor-childs-doctor-talk-childs-parent-about-patients-mental-health-status-and-needs.html).

Primary commercial insurance with secondary Medicaid must not create family collection of protected Colorado behavioral-health copays/deductibles. A generic waiver does not create a noncovered-service private-pay exception. [HCPF behavioral-health/TPL guidance](https://hcpf.test.colorado.gov/bh-policies).

## Validation

Backend unit/security suites cover encryption, ownership, coverage, processor binding, cents, aging, clinical grants and legacy checkout verification. Disposable MySQL tests exercise actual migrations, encryption, concurrent cash retries, split allocations, card captures, refund holds, signed plans/tasks, source fulfillment and practitioner credit activation. Stripe and outbound services are mocked. Signature testing renders an actual PNG from a synthetic stored logo with mocked storage.

Vue component tests cover authorization-only enrollment, owned-card task submission, cross-account errors, private shared balances, stable payment retries and tenant switching. Actual Vue screens were browser-reviewed at 320, 390, 768, 1024 and 1440 pixels with no page overflow, clipped controls or browser exceptions. The staff table scrolls horizontally within its container on mobile. Production frontend build passes with the repository's existing large-chunk warnings.
