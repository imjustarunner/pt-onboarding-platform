Hogwarts school portal demo (offline)
=====================================

This zip is a frozen copy of the Hogwarts school portal demo. After you unzip it,
you can browse the demo on this computer with no internet connection.

What you need
-------------
Node.js 18 or newer: https://nodejs.org
(LTS is fine. You do not need MySQL, Docker, or an account.)

How to start
------------
macOS:  double-click start.command
        If macOS blocks it: right-click → Open, then confirm.
Windows: double-click start.bat
Linux:   run ./start.sh

Your browser should open:
  http://127.0.0.1:8080/school-onboarding/demo

If it does not, copy that address into Chrome or Safari.

Emailing this file
------------------
The zip can be larger than a typical email attachment. If send fails,
share it with Google Drive, Dropbox, or WeTransfer and email the link.
The person who receives it unzips on their computer and double-clicks start.

Notes
-----
- This is a view-only snapshot. Edits are not saved.
- Stop the demo with Ctrl+C in the terminal window, or close that window.
