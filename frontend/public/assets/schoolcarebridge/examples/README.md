# Actual SchoolCareBridge interface captures

`school-portal.png` and `agency-overview.png` were captured in Chrome at 1440×1000 from the working `/schoolcarebridge/demo` entry, using the actual `SchoolPortalView` and `SchoolOverviewDashboard` components.

Every person, school and record shown comes from `src/schoolcarebridge/demo/fixtures.js`. No production student, provider or agency data is included. These captures can be refreshed by visiting the demo home and `?view=overview` after the interface and images finish loading. The website also embeds the same interactive demo; the images are its initial lightweight preview.
