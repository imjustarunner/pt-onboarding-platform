# Brand typography

The owner selected Comfortaa for ITSCO and Montserrat for Next Level Up, Inner Strength Institute and Plot Twist CO on October 10, 2026. Public website and handbook typography use the shared variables in `src/styles/brandTypography.css`.

Montserrat is bundled as a normal-style variable font with weights 100–900. Source: `https://raw.githubusercontent.com/google/fonts/main/ofl/montserrat/Montserrat[wght].ttf`. Its accompanying SIL Open Font License is `Montserrat-OFL.txt` in this directory.

Comfortaa reuses the existing variable font at `../business-cards/Comfortaa-Variable.ttf`, with its accompanying `Comfortaa-OFL.txt`, and supports weights 300–700.

Both fonts load from the application assets rather than depending on a third-party font request. Text already embedded in supplied cover images or logos remains part of those images.
